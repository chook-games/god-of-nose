# God of Nose: Sneeze and Thunder

A 2D action game for Android built with **Kotlin + Jetpack Compose**.

> **Download:** grab the latest `GodOfNose.apk` from the [Releases](https://github.com/chook-games/god-of-nose/releases) page and install it on your Android device.

## Features

- Fast, humorous 2D action
- Built with Jetpack Compose
- Simple controls, quick sessions

## Build

```bash
./gradlew assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`.
